## BASIC COMMANDS:

```bash
head -n 3 file.txt
```
> Displays only first three lines from the file.txt

***

```bash
tail -n 3 file.txt
```
> Displays only last three lines from the file.txt
 
 ***

 - `-n` option is used to specify the number of lines to be printed/displayed
