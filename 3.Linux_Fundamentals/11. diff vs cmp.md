# `diff` vs `cmp`

| Command | Purpose |
|---------|---------|
| `diff` | Compares **two files line by line** and displays the differences. |
| `cmp` | Compares **two files byte by byte** and reports the **first difference**. |

## `diff` Command

**Syntax:**
```bash
diff file1.txt file2.txt
```

**Example Output:**
```text
1c1
< hello world
---
> hello linux
```

- Compares files **line by line**.
- Shows **which lines are different**.
- Useful for comparing text files, source code, and configuration files.

---

## `cmp` Command

**Syntax:**
```bash
cmp file1.txt file2.txt
```

**Example Output:**
```text
file1.txt file2.txt differ: byte 7, line 1
```

- Compares files **byte by byte**.
- Reports the **first byte and line** where the files differ.
- Useful for checking if two files are **exactly identical**.

---

## Whitespace Matters

Even a **single whitespace** (space, tab, or extra blank line) changes the file content.

Example:

**file1.txt**
```text
hello world
```

**file2.txt**
```text
hello␠␠world
```

Although they look almost the same, both `diff` and `cmp` will detect them as **different** because the extra space changes the file's bytes.

> **Note:** Whitespace (spaces, tabs, and newlines) is stored as bytes in a file, so any change in whitespace causes a difference during comparison.

- `diff` command is used for line based differences.
- `cmp` command is used for binary/byte level differences.
