# Tab Completion & Up Arrow Keys

These are useful shell shortcuts that improve speed and reduce typing errors while working in the Linux terminal.

---

## 1. Tab Completion

Press the **`Tab`** key while typing a command, file name, or directory name.

**Description:** Automatically completes the command or filename if it is unique.

**Example:**

```bash
cd Doc<Tab>
```

Automatically completes to:

```bash
cd Documents/
```

If multiple matches exist, press **`Tab`** twice to display all possible completions.

---

## 2. Up Arrow Key (`↑`)

Press the **Up Arrow (`↑`)** key.

**Description:** Retrieves previously executed commands from the command history.

This saves time by avoiding the need to retype frequently used commands.

---

## 3. Execute a Command from History

```bash
!56
```

**Description:** Executes the **56th command** from the command history.

To view the command history:

```bash
history
```

**Example Output:**

```text
54  ls
55  pwd
56  mkdir project
57  cd project
```

Running:

```bash
!56
```

will execute:

```bash
mkdir project
```

---

## Other Useful History Commands

| Command | Description |
|---------|-------------|
| `history` | Displays all previously executed commands. |
| `!!` | Executes the last command again. |
| `!56` | Executes the 56th command from history. |
| `!mkdir` | Executes the most recent command that starts with `mkdir`. |

> **Tip:** Use **Tab Completion** to type faster and **Up Arrow** or **history** to quickly reuse previous commands.
