# HELP COMMANDS

- `command --help` is the basic syntax

eg:
```
ls --help
```
- This --help command shows the entire options which we can use with `ls` command

- `man ls` (manual)- gives manual of command `ls `which is more detailed that --help.
- `info ls` gives more detailed information regarding `ls` command
- `whatis ls` is used to get one line info about the command. It tells what command actually does.

## Conclusion

Linux provides multiple ways to get help for commands, each serving a different purpose:

| Command | Purpose |
|---------|---------|
| `command --help` | Displays a quick list of options and syntax. |
| `man command` | Opens the complete manual page with detailed documentation. |
| `info command` | Provides more comprehensive documentation with navigation support. |
| `whatis command` | Gives a one-line description of what the command does. |

**Tip:** Use `--help` for quick reference, `man` for detailed usage, `info` for in-depth documentation, and `whatis` when you only need a brief description of a command.
