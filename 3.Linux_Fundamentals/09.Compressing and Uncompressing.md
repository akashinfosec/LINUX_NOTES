# COMPRESSING & UNCOMPRESSING

## `tar` (Tape Archive)

`tar` is used to **archive** files and folders. By default, it only bundles files together. Compression is added using flags like `-z`.

### Syntax

```bash
tar [options] [archive_name] [file_or_folder]
```

### Common Flags

| Flag | Description |
|------|-------------|
| `-c` | Create a new archive |
| `-x` | Extract an archive |
| `-t` | List the contents of an archive |
| `-z` | Compress using `gzip` |
| `-j` | Compress using `bzip2` |
| `-v` | Verbose (shows progress) |
| `-f` | Specify the archive filename |

### Examples

**Create a compressed archive**
```bash
tar -czvf archive.tar.gz my_folder/
```

**Extract a compressed archive**
```bash
tar -xzvf archive.tar.gz
```

---

## `zip` and `unzip`

`zip` is commonly used for compatibility with Windows systems.

### Syntax

```bash
zip [options] archive_name files
```

```bash
unzip archive_name
```

### Examples

**Compress a folder**
```bash
zip -r my_files.zip folder_name/
```

> `-r` is required when compressing folders.

**Extract a ZIP archive**
```bash
unzip my_files.zip
```

---

## Common Commands

| Action | Gzip Style | Zip Style |
|--------|------------|-----------|
| Compress Folder | `tar -czvf file.tar.gz folder/` | `zip -r file.zip folder/` |
| Extract | `tar -xzvf file.tar.gz` | `unzip file.zip` |
| List Contents | `tar -tvf file.tar.gz` | `unzip -l file.zip` |

# Differences

## 1. `tar -cvf` vs `tar -tvf` vs `tar -xvf`

| Command | Purpose |
|---------|---------|
| `tar -cvf archive.tar folder/` | Create a new archive |
| `tar -tvf archive.tar` | List the contents of an archive without extracting |
| `tar -xvf archive.tar` | Extract files from an archive |

## 2. `gzip` vs `gunzip`

| Command | Purpose |
|---------|---------|
| `gzip file.tar` | Compress a file (`file.tar` → `file.tar.gz`) |
| `gunzip file.tar.gz` | Uncompress a `.gz` file (`file.tar.gz` → `file.tar`) |
> When file.tar gets compressed to file.tar.gz the original file (file.tar) gets replaced by compressed file (file.tar.gz). When file.tar.gz gets uncompressed the compressed file gets replaced by the original file.
- To keep the original file after compression `-k` (keep) option is used along with gzip.
- option `-c` is used to show the contents of the file while unzipping/decompressing.

# Common `gzip` and `gunzip` Options

| Option | Description | Example |
|--------|-------------|---------|
| `-k` | Keep the original file after compression/decompression. | `gzip -k file.txt` |
| `-d` | Decompress a `.gz` file (same as `gunzip`). | `gzip -d file.txt.gz` |
| `-c` | Write output to standard output (stdout). | `gzip -c file.txt > file.txt.gz` |
| `-l` | Display compressed file information (size, ratio, name). | `gzip -l file.txt.gz` |
| `-r` | Compress/decompress files recursively in directories. | `gzip -r folder/` |
| `-v` | Verbose mode (shows compression details). | `gzip -v file.txt` |
| `-1` | Fastest compression (less compression). | `gzip -1 file.txt` |
| `-9` | Best compression (slower). | `gzip -9 file.txt` |
| `-f` | Force compression/decompression (overwrite existing files). | `gzip -f file.txt` |
| `-t` | Test the integrity of a compressed file. | `gzip -t file.txt.gz` |

## `gunzip` Common Options

| Option | Description | Example |
|--------|-------------|---------|
| `-k` | Keep the compressed `.gz` file after decompression. | `gunzip -k file.txt.gz` |
| `-c` | Write decompressed data to stdout. | `gunzip -c file.txt.gz` |
| `-f` | Force decompression. | `gunzip -f file.txt.gz` |
| `-r` | Decompress files recursively. | `gunzip -r folder/` |
| `-t` | Test compressed file integrity without decompressing. | `gunzip -t file.txt.gz` |
| `-v` | Verbose mode. | `gunzip -v file.txt.gz` |

> **Note:** `gunzip` is equivalent to `gzip -d`.

## 3. `ls -l` vs `ls -lh`

| Command | Purpose |
|---------|---------|
| `ls -l` | Shows detailed file information with file size in bytes |
| `ls -lh` | Shows detailed file information with human-readable file sizes (KB, MB, GB) |

### Example

```bash
ls -l
```

```text
-rw-r--r-- 1 user user 1048576 Aug 3 notes.txt
```

```bash
ls -lh
```

```text
-rw-r--r-- 1 user user 1.0M Aug 3 notes.txt
```

## gzip vs bzip2 comparison

## `gzip` vs `bzip2`

| Feature | `gzip` | `bzip2` |
|---------|--------|---------|
| Compression Speed | ✅ Faster | ❌ Slower |
| Decompression Speed | ✅ Faster | ❌ Slower |
| Compression Ratio | Good | Better (Smaller File Size) |
| CPU Usage | Low | High |
| Memory Usage | Low | Higher |
| Compression Algorithm | DEFLATE | Burrows-Wheeler + Huffman Coding |
| File Extension | `.gz` | `.bz2` |
| Compression Command | `gzip file.txt` | `bzip2 file.txt` |
| Decompression Command | `gunzip file.txt.gz` | `bunzip2 file.txt.bz2` |
| Best Use Case | Faster compression and decompression | Maximum compression with less storage space |
| Common Tar Archive | `.tar.gz` (`.tgz`) | `.tar.bz2` (`.tbz2`) |

### Quick Summary

- 🚀 **`gzip`** → Faster, lower CPU usage, good compression.
- 📦 **`bzip2`** → Slower, higher CPU usage, better compression (smaller file size).

## My Questions

> How actually compression wokrs? How a compressed file returns to its original file size after compression? How a 100MB file turns into 50MB and returns again to 100Mb after decompression?

### How File Compression Works (Layman Terms)

- File compression **reduces file size by storing data in a smarter and more efficient way**.
- It **does not delete any information** (lossless compression).
- Compression algorithms identify **repeated patterns** and replace them with shorter representations.
- During decompression, these shorter representations are expanded back to the **exact original data**.
- That's why a **100 MB** file can become **50 MB**, and after decompression it returns to **100 MB** with no data loss.

#### Example

Original Data:
```text
HAHAHAHAHAHAHAHA
```

Compressed Representation:
```text
HA × 8
```

After Decompression:
```text
HAHAHAHAHAHAHAHA
```

##### Key Points

- 📦 **Compression** → Stores data more efficiently.
- 🔄 **Decompression** → Restores the original file exactly.
- ✅ No data is lost in **lossless compression** (`gzip`, `bzip2`).
- 📄 Text files compress well because they contain many repeated patterns.
- 🎵 Files like `.mp3`, `.mp4`, `.jpg`, and `.zip` usually compress very little because they are already compressed.
