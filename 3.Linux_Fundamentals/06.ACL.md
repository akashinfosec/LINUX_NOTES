# ACCESS CONTROL LIST (ACL)

- It is a advanced permission mechanism which is used to set fine grained permissions.

# Access Control Lists (ACL)

ACL (Access Control List) allows you to assign specific permissions to individual users or groups, beyond the standard owner, group, and others permissions.

---

## 1. Check if ACL is Supported

```bash
mount | grep acl
```

**Description:** Checks whether the mounted filesystem has ACL support enabled.

---

## 2. View ACL of a File or Directory

```bash
getfacl filename
```

**Description:** Displays the current ACL entries and permissions of a file or directory.

**Example:**

```bash
getfacl demo.txt
```

---

## 3. Set ACL for a User

```bash
setfacl -m u:username:permissions filename
```

**Description:** Grants specific permissions to an existing user on a file or directory.

**Example:**

```bash
setfacl -m u:alice:r file.txt
```

Grant read permission to user `alice`.

```bash
setfacl -m u:alice:rw file.txt
```

Grant read and write permissions to user `alice`.

> **Note:** The specified user must already exist on the system.

---

## 4. Set ACL for a Group

```bash
setfacl -m g:groupname:permissions filename
```

**Description:** Assigns custom permissions to a specific group.

**Example:**

```bash
setfacl -m g:developers:rw file.txt
```

Grant read and write permissions to the `developers` group.

---

## 5. Remove an ACL Entry

```bash
setfacl -x u:username filename
```

**Description:** Removes the ACL permissions assigned to a specific user.

**Example:**

```bash
setfacl -x u:alice file.txt
```

Remove ACL entry for user `alice`.

---

## 6. Set Default ACL on a Directory

```bash
setfacl -d -m u:username:permissions directory/
```

**Description:** Sets default ACL permissions that are automatically inherited by new files and subdirectories created inside the directory.

**Example:**

```bash
setfacl -d -m u:alice:rw project/
```

Any new file or folder created inside `project/` will inherit these ACL permissions.

---

# Useful ACL Permission Symbols

| Permission | Meaning |
|------------|---------|
| `r` | Read |
| `w` | Write |
| `x` | Execute |
| `rw` | Read + Write |
| `rwx` | Read + Write + Execute |

---

# Common ACL Commands

| Command | Purpose |
|---------|---------|
| `getfacl file` | View ACL of a file or directory |
| `setfacl -m ...` | Modify or add an ACL entry |
| `setfacl -x ...` | Remove a specific ACL entry |
| `setfacl -b file` | Remove all ACL entries from a file |
| `setfacl -d -m ...` | Set default ACL on a directory |

---

## Notes

- ACL provides more fine-grained permission control than the traditional Linux permission model.
- ACL entries can only be assigned to **existing users or groups**.
- Use `getfacl` after modifying permissions to verify the changes.
