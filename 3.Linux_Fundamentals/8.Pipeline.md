# PIPE (`|`) IN LINUX

The **pipe (`|`)** is used to **send the output of one command as the input to another command**.

Instead of saving the output to a file, you can directly pass it to the next command.

### Syntax
```bash
command1 | command2
```

- `command1` → Produces the output.
- `command2` → Uses that output as its input.

---

## Example 1: Filter Files

```bash
ls -l | grep ".sh"
```

### How it works:
1. `ls -l` lists all files and directories.
2. `grep ".sh"` searches only for files containing `.sh`.

**Output:**
```text
-rwxr-xr-x 1 user user 120 Aug 3  script.sh
```

---

## Example 2: Count Number of Files

```bash
ls | wc -l
```

### How it works:
1. `ls` lists all files.
2. `wc -l` counts the number of lines.

**Output:**
```text
12
```

---

## Example 3: Search Running Processes

```bash
ps -ef | grep chrome
```

### How it works:
1. `ps -ef` displays all running processes.
2. `grep chrome` filters only Chrome-related processes.

---

## Example 4: Find Logged-in User

```bash
who | grep akash
```

### How it works:
1. `who` shows all logged-in users.
2. `grep akash` displays only the entry for user **akash**.

---

## Example 5: Display Only Directories

```bash
ls -l | grep "^d"
```

### How it works:
- `ls -l` lists all files and directories.
- `grep "^d"` filters only directories.

---

## Why Use Pipes?

Without a pipe:
- Run one command.
- Copy its output.
- Use it in another command.

With a pipe:
- Commands are connected automatically.
- Faster and more efficient.
- Saves time and avoids temporary files.

---

## Remember

> **Pipe (`|`) = Take the output of one command and pass it directly as the input to another command.**

Think of it like a **water pipe**:
- First command = Water source 🚰
- Pipe (`|`) = Water pipe
- Second command = Destination 🚿

The output flows from one command to the next.

---

## Quick Summary

| Command | Purpose |
|---------|---------|
| `ls -l \| grep ".sh"` | Show only `.sh` files |
| `ls \| wc -l` | Count files/directories |
| `ps -ef \| grep chrome` | Find Chrome processes |
| `who \| grep akash` | Find a logged-in user |
| `ls -l \| grep "^d"` | Show only directories |
