# USER AND PERMISSION MANAGEMENT

## The **whoami** command prints the name of current logged in user name.

### Basicallly there are three types of user permissions
- r (read)
- w (write)
- x (execute)

### Each permission (rwx) can be controlled at three levels
- u (user level)
- g (group level)
- o (others- external member/user or users who are not related to the project)

### NOTE
`-` - indicates its a file
`d` - indicates its a directory

``` ls -l
-     rwx   rwx    rwx
file  user  group  others
```

-**EXAMPLE 1**

/- rw_ _wx ___

-In above example user level have read and write permissions , group level have write and execute permissions while others have no permission

- `chmod` (change modifications) command is used to give or take away the permissions at 3 levels (u,g and 0)

**EXAMPLE 2**
```
chmod g-w filename
```
- The above command will remove the write permission for file at group level

**EXAMPLE 3**
```
chmod u+w file1
```
- The above command will give the write permission for file1 at user level

### FILE PERMISSSIONS USING NUMERIC MODE

- Giving and taking away permissions at all three levels using numeric mode becomes very easy and faster rather than typing manually.

| Number | Permission Type         | Symbol (rwx) | Meaning                              |
|--------|--------------------------|--------------|--------------------------------------|
| 0      | No permission            | `---`        | No read, no write, no execute        |
| 1      | Execute only             | `--x`        | Can run/execute the file             |
| 2      | Write only               | `-w-`        | Can modify/write the file            |
| 3      | Write + Execute          | `-wx`        | Can write and execute                |
| 4      | Read only                | `r--`        | Can read the file                    |
| 5      | Read + Execute           | `r-x`        | Can read and execute                 |
| 6      | Read + Write             | `rw-`        | Can read and write                   |
| 7      | Read + Write + Execute   | `rwx`        | Full permission                      |

```
chmod 777 file1
```
- 777 (user level, group level,others level)
- above command indicates that file1 have all type of permissions

- **NOTE**: file1 (appears green in colour) then it have all permissions (rwx)

# CH OWN (change ownership of file)

- `chown file1` :- This command is used to change the ownership of a file at user level
- `chgro file1` :- This command is used to change the ownership of a file at group level
