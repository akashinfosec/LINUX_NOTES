# EXECUTING MULTIPLE COMMANDS

```bash
ls ; pwd ; whoami
```
- works independdently
- one fails , next one will still work

eg:
```bash
echo "hello world" > hello.txt : cat hello.txt
```
- `echo "hello world"` simply prints the hello world text
- `>` this operater redirects the text into other file called hello.txt
- If hello.txt already exists then it simply echoes the desired text. If the file doesnt exist then firstly it will create new file called hello.txt then simply echoes in it.
- `;` used to chain multiple commands at once
- finally `cat hello.txt` command displays what actually is inside the hello.txt file
