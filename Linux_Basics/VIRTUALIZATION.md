
==IT IS A TECHNOLOGY THAT ENABLES TO CREATE DIFFERENT VIRUTAL MACHINES ON A SINGLE MACHINE.==

THINK OF IT LIKE A BIG POWERFUL COMPUTER. EACH FLAT INSIDE IS A DIFFERENT VIRUTAL MACHINE
-EACH FLAT HAS ITS OWN OS
-THEY DONT INTERFERE WITH EACH OTHER
-THEY SHARE SAME BUILDING OR HARDWARE

===HYPERVISER===  IS USED TO CREATE DIFFERENT VIRUTAL MACHINES USING PHYSICAL HARDWARE.

COMPONENTS OF THE VM:
1.GUEST OS
2.VCPU
3.VRAM
4.VIRUTAL DISK


===OS VIRTUALIZATION===
-WE CAN FURTHER DIVIDE A VM INTO DIFFERENT VM LIKE ENVIRONMENT. THESE ARE CALLED CONTAINERS.
-EACH CONTAINER CAN RUN ON DIFFERENT OS.
-ALL CONTAINERS  ARE ISOLATED FROM EACH OTHER
-THEY SHARE COMMON KERNEL.
