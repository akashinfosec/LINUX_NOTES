| Command | Meaning                      |
| ------- | ---------------------------- |
| `i`     | Enter Insert Mode            |
| `Esc`   | Return to Command Mode       |
| `:w`    | Save the file                |
| `:q`    | Quit                         |
| `:wq`   | Save and quit                |
| `:q!`   | Quit without saving          |
| `dd`    | Delete the current line      |
| `yy`    | Copy (yank) the current line |
| `p`     | Paste copied text            |

vi file_name

-vi command enables to edit the file. vi stands for visual text
