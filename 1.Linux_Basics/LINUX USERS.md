THERE ARE THREEE TYPES OF LINUX USERS
1.ROOT USER(UID=O)- CONTROLS EVERYTHING ON A HARDWARE LEVEL, ALSO CONTROL USER ACCESS AND SYSTEM ACCESS.

2.NORMAL/REGULAR USERS(UID>1000)
normal user can use "SUDO (SUPER USER DO COMMAND )" to access root level user access and privileges

3.SYSTEM USERS (UID<1000)- ACCESS TO SERVERS AND DATABASES
