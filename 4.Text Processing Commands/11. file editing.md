# 📄 File Editing in Linux

## What is a File Editor?

A **text editor** is a program used to **create, edit, and manipulate text/data in Linux files**.

Common Linux text editors include:

- `vi` → Visual Editor
- `ed` → Standard line editor
- `ex` → Extended line editor
- `emacs` → Full-screen editor
- `pico` → Beginner-friendly editor
- `vim` → Advanced version of `vi`

> **`vi` is a classic, terminal-based text editor available on almost all Linux systems.**

---

# `vi` Editor

**`vi`** stands for **Visual Editor**.

It is a **terminal-based, lightweight text editor** commonly available on Unix/Linux systems.

**`vim`** (Vi Improved) is a modern version of `vi` with additional features.

---

# Modes in `vi`

`vi` has **three main modes**:

| Mode | Purpose |
|------|---------|
| **Command Mode** | Navigation and editing commands. This is the default mode. |
| **Insert Mode** | Typing and inserting text. |
| **Last Line (Ex) Mode** | Saving, quitting, searching, and other commands. |

## Switching Modes

| Command/Key | Action |
|-------------|--------|
| `i` | Enter Insert Mode and insert text before the cursor. |
| `Esc` | Return to Command Mode. |
| `:` | Enter Last Line (Ex) Mode. |

---

# Basic `vi` Commands

## Navigation

| Command | Description |
|---------|-------------|
| `h` | Move left. |
| `l` | Move right. |
| `k` | Move up. |
| `j` | Move down. |
| `0` | Go to the beginning of the line. |
| `$` | Go to the end of the line. |
| `G` | Go to the end of the file. |
| `gg` | Go to the beginning of the file. |

### Easy Memory Trick

```text
      k
      ↑
h ←       → l
      ↓
      j
```

---

# Searching

| Command | Description |
|---------|-------------|
| `/word` | Search forward for `word`. |
| `?word` | Search backward for `word`. |
| `n` | Repeat the last search. |

Example:

```text
/Linux
```

Searches forward for **Linux**.

```text
?Linux
```

Searches backward for **Linux**.

---

# File Operations

| Command | Description |
|---------|-------------|
| `:w` | Save/write the file. |
| `:q` | Quit `vi`. |
| `:wq` | Save and quit. |
| `ZZ` | Save and quit. |
| `:q!` | Quit without saving changes. |

---

# Inserting Text

| Command | Description |
|---------|-------------|
| `i` | Insert text before the cursor. |
| `a` | Append text after the cursor. |
| `o` | Open a new line below the current line. |
| `O` | Open a new line above the current line. |

---

# Deleting Text

| Command | Description |
|---------|-------------|
| `x` | Delete the character under the cursor. |
| `dd` | Delete (cut) the entire line. |
| `dw` | Delete a word. |

---

# Copy & Paste

| Command | Description |
|---------|-------------|
| `yy` | Yank (copy) the current line. |
| `p` | Paste after the cursor. |
| `P` | Paste before the cursor. |
| `u` | undo the process, Its like CTRL+Z in vi. |

---

# Adding Text to Files

There are **3 simple ways** to add text to a file:

| Method | Purpose |
|--------|---------|
| `vi` | Open and edit a file using the `vi` editor. |
| `>` / `>>` | Redirect command output to a file. |
| `echo >` / `echo >>` | Write or append text using `echo`. |
