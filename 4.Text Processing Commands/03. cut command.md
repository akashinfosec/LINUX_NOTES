# ✂️ `cut` Command

The **`cut`** command is used to **extract specific columns (fields) or characters** from each line of a file.

## Syntax

```bash
cut [OPTIONS] file
```

---

# Example Employee Table (`employee.txt`)

```text
101,Akash,IT,50000
102,Rahul,HR,45000
103,Priya,Finance,60000
104,Rohit,Sales,55000
```

Here the delimiter is **`,` (comma)**.

| Field | Value |
|-------|-------|
| **Field 1 (`-f1`)** | Employee ID |
| **Field 2 (`-f2`)** | Name |
| **Field 3 (`-f3`)** | Department |
| **Field 4 (`-f4`)** | Salary |

> **Note:** `-f1` means **Field 1 (Column 1)**, `-f2` means **Field 2 (Column 2)**, and so on.

---

# Common Options

## 1. `-d` (Delimiter)

Specifies the character used to separate fields.

```bash
cut -d "," -f2 employee.txt
```

### Output

```text
Akash
Rahul
Priya
Rohit
```

Here,

- `-d ","` → Comma is the delimiter.
- `-f2` → Print **Field 2 (Name)**.

---

## 2. `-f` (Field)

Selects one or more columns.

### First Column

```bash
cut -d "," -f1 employee.txt
```

**Output**

```text
101
102
103
104
```

### Multiple Columns

```bash
cut -d "," -f2,4 employee.txt
```

**Output**

```text
Akash,50000
Rahul,45000
Priya,60000
Rohit,55000
```

---

## 3. `--complement`

Prints **all fields except** the selected one(s).

```bash
cut -d "," -f3 --complement employee.txt
```

### Output

```text
101,Akash,50000
102,Rahul,45000
103,Priya,60000
104,Rohit,55000
```

Here, **Field 3 (Department)** is removed.

---

## 4. `--output-delimiter`

Changes the delimiter in the output.

```bash
cut -d "," -f1,2 --output-delimiter=" | " employee.txt
```

### Output

```text
101 | Akash
102 | Rahul
103 | Priya
104 | Rohit
```

Instead of a comma, the output uses **`|`**.

---

## 4. `cut -c command`
- Cuts the specific character using position at every line of the file. 
- Doesn't care about spaces and commas. White spaces and commas are considered as characters.

```bash
cut -c 1-3 employee.txt
```
### Output:
```text
101
102
103
104
```
```bAH
cut -c 1-8 employee.txt
```
### Output:
```text
101,Akas
102,Rahu
103,Priy
104,Rohi
```
## 5. `cut using head command`

```bash
head -1 employee.txt | cut -c 1-3
```

**Output**

```text
101
```

**Explanation**

- `head -1 employee.txt` → Reads only the **first line** of the file.
- `|` → Passes the output of `head` to the next command.
- `cut -c 1-3` → Extracts the **first 3 characters** (Employee ID).

---

# Summary Table

| Option | Description |
|---------|-------------|
| `-c` | Extract characters by position. |
| `-d` | Specify the field delimiter (e.g., `,`, `:`, `|`). |
| `-f` | Select field(s)/column(s). (`-f1` = Column 1, `-f2` = Column 2) |
| `-s` | Skip lines that do not contain the delimiter. |
| `--complement` | Print everything except the selected field(s) or characters. |
| `--output-delimiter` | Replace the original delimiter in the output with a new one. |

---

# Quick Revision

- `-d` → Defines the **delimiter**.
- `-f1` → **Field 1 / Column 1**.
- `-f2` → **Field 2 / Column 2**.
- `-f3` → **Field 3 / Column 3**.
- `-f4` → **Field 4 / Column 4**.
- `--complement` → Excludes the selected field(s).
- `--output-delimiter` → Changes the output separator.
- `-c` → Cuts by character position.
- `-s` → Skips lines without the specified delimiter.
