# 📄 `cat` Command

**`cat` (Concatenate)** is used to **display, create, append, and merge** text files.

## Syntax

```bash
cat [OPTIONS] filename
```

## Common Uses

```bash
# Display a file
cat file.txt

# Display multiple files
cat file1.txt file2.txt

# Create a file (Ctrl + D to save)
cat > file.txt

# Append to a file (Ctrl + D to save)
cat >> file.txt

# Merge files
cat file1.txt file2.txt > merged.txt
```

---

# Common Options

| Option | Description |
|---------|-------------|
| `-n` | Number all lines. |
| `-b` | Number only non-empty lines. |
| `-s` | Remove repeated blank lines. |
| `-E` | Show `$` at the end of each line. |
| `-T` | Show tabs as `^I`. |
| `-A` | Show all non-printing characters. |

### `-n` vs `-b`

| `-n` | `-b` |
|------|------|
| Numbers all lines. | Numbers only non-empty lines. |
| Blank lines are also numbered. | Blank lines are ignored. |

# `<<EOF` (Here Document)

A **Here Document (Heredoc)** lets you provide **multi-line input** directly to a command.

## Syntax

```bash
command <<EOF
text
EOF
```

- `<<` → Read input until the delimiter is found.
- `EOF` → End marker (can be any word like `END`, `STOP`, etc.).

## Examples

### Display Multi-line Text

```bash
cat <<EOF
Hello
Linux
EOF
```

### Create a File

```bash
cat <<EOF > notes.txt
Linux
Commands
EOF
```

### Append to a File

```bash
cat <<EOF >> notes.txt
grep
find
EOF
```

---

# `cat > file` vs `cat <<EOF > file`

| `cat > file` | `cat <<EOF > file` |
|---------------|--------------------|
| Manual input. | Predefined multi-line input. |
| Press **Ctrl + D** to finish. | Ends automatically at `EOF`. |
| Best for interactive use. | Best for scripts and automation. |

---

# Summary

- `cat` → Display, create, append, or merge text files.
- `cat > file` → Create a file.
- `cat >> file` → Append to a file.
- `cat file1 file2 > newfile` → Merge files.
- `-n` → Number all lines.
- `-b` → Number only non-empty lines.
- `-s` → Remove repeated blank lines.
- `-E` → Show end-of-line (`$`).
- `-T` → Show tabs (`^I`).
- `-A` → Show all non-printing characters.
- `<<EOF` → Provide multi-line input to a command without pressing `Ctrl + D`.
- `EOF` → Just a delimiter name; it can be replaced with any matching word.
