# 📄 `echo` Command

## Definition

The **`echo`** command is used to **display text, messages, and variable values** on the terminal.

It is also commonly used in **shell scripts** to display information or generate output.

## Syntax

```bash
echo [OPTIONS] [TEXT]
```

---

## Basic Working

```bash
echo "Hello Linux"
```

**Output:**

```text
Hello Linux
```

`echo` simply sends the given text to the terminal.

---

# Common Options

| Option | Description |
|--------|-------------|
| `-e` | Enables interpretation of escape sequences such as `\n` and `\t`. |
| `-n` | Does not print a newline at the end. |
| `-E` | Disables interpretation of escape sequences (default in many implementations). |

---

## 1. `-e` → Enable Escape Sequences

```bash
echo -e "Hello\nLinux"
```

**Output:**

```text
Hello
Linux
```

Common escape sequences:

```text
\n → New line
\t → Tab
\\ → Backslash
```

---

## 2. `-n` → No Newline

Normally, `echo` moves to a new line after printing.

```bash
echo "Hello"
echo "Linux"
```

Output:

```text
Hello
Linux
```

With `-n`:

```bash
echo -n "Hello"
echo "Linux"
```

Output:

```text
HelloLinux
```

---

## 3. `-E` → Disable Escape Sequences

```bash
echo -E "Hello\nLinux"
```

Output:

```text
Hello\nLinux
```

The `\n` is printed as it is instead of creating a new line.

---

# Using Variables

`echo` can also display the value of a variable.

```bash
name="Sky"
echo $name
```

**Output:**

```text
Sky
```

You can also use:

```bash
echo "Hello $name"
```

**Output:**

```text
Hello Sky
```

---

# Quick Revision

- `echo` → Displays text or variable values.
- `-e` → Enables escape sequences.
- `-n` → Does not add a newline.
- `-E` → Disables escape-sequence interpretation.
- `$variable` → Displays the value of a variable.
