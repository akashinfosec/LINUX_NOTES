# 📝 `awk` Command

## 1. Definition

**`awk`** stands for **Aho, Weinberger, and Kernighan**, named after its creators.

It is a **powerful text processing and pattern scanning** command used to **search, filter, extract, manipulate, and format** data from files or command output.

`awk` processes data **line by line** and automatically splits each line into **fields (columns)**.

---

## Syntax

```bash
awk 'pattern { action }' file
```

or

```bash
awk -F "delimiter" '{ action }' file
```

- **Pattern** → Condition to match (optional)
- **Action** → Operation to perform
- **`-F`** → Field separator (delimiter)

---

## What `awk` Can Do

- Extract specific columns
- Search for patterns
- Filter records
- Format output
- Perform calculations
- Generate reports

---

# 2. `cat` vs `awk`

| `cat` | `awk` |
|--------|--------|
| Displays the entire file. | Processes and filters file contents. |
| Cannot work with individual columns. | Can extract specific fields (columns). |
| No data manipulation. | Can manipulate, format, and calculate data. |
| Simple file viewing. | Powerful text-processing tool. |

---

# Example File (`employees.txt`)

```text
101,Akash,IT,50000
102,Rahul,HR,45000
103,Priya,Finance,60000
104,Rohit,Sales,55000
```

| Field | Meaning |
|-------|---------|
| `$1` | Employee ID |
| `$2` | Name |
| `$3` | Department |
| `$4` | Salary |

---

# 3. Basic `awk` Commands

### Print One Field

```bash
awk -F "," '{print $2}' employees.txt
```

**Output**

```text
Akash
Rahul
Priya
Rohit
```

---

### Print Multiple Fields

```bash
awk -F "," '{print $2, $4}' employees.txt
```

**Output**

```text
Akash 50000
Rahul 45000
Priya 60000
Rohit 55000
```

---

### Filter Using a Condition

```bash
awk -F "," '$4 > 50000 {print $2 " --> " $4}' employees.txt
```

**Output**

```text
Priya --> 60000
Rohit --> 55000
```

**Explanation**

- `-F ","` → Comma is the delimiter.
- `$4 > 50000` → Select employees with salary greater than **50000**.
- `$2` → Employee Name.
- `$4` → Salary.
- `" --> "` → Prints an arrow between the name and salary.

---

# 4. `substr()` Function

The **`substr()`** function extracts part of a string.

## Syntax

```bash
substr(string, start, length)
```

Example:

```bash
awk -F "," '{print substr($2,1,3)}' employees.txt
```

**Output**

```text
Aka
Rah
Pri
Roh
```

Here,

- `$2` → Name
- `1` → Start from first character
- `3` → Print 3 characters

---

# 5. `for` Loop and `NF`

### What is `NF`?

**`NF`** stands for **Number of Fields**.

It stores the **total number of fields (columns)** in the current line.

Example:

```text
101,Akash,IT,50000
```

There are **4 fields**, so:

```text
NF = 4
```

---

### Print All Fields Using `for`

```bash
awk -F "," '{
    for(i=1; i<=NF; i++)
        print $i
}' employees.txt
```

**Output**

```text
101
Akash
IT
50000
102
Rahul
HR
45000
...
```

### Explanation

- `i=1` → Start from Field 1.
- `i<=NF` → Continue until the last field.
- `NF` → Total number of fields in the current line.
- `$i` → Prints the current field.

---

# 6. Changing Header Using `NR`

### What is `NR`?

**`NR`** stands for **Number of Records** (current line number).

Example:

```bash
awk -F "," 'NR==1 {$1="Emp_ID"} {print}' employees.txt
```

If the first line is:

```text
ID,Name,Dept,Salary
```

**Output**

```text
Emp_ID Name Dept Salary
101 Akash IT 50000
102 Rahul HR 45000
...
```

### Explanation

- `NR==1` → Executes only for the first line.
- `$1="Emp_ID"` → Replaces the first column value.
- `{print}` → Prints every line.
