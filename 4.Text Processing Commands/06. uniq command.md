# 📄 Common `uniq` Options

| Option | Description |
|---------|-------------|
| `-c` | Display the count of consecutive duplicate lines. |
| `-d` | Display only the duplicate lines. |
| `-u` | Display only the unique (non-duplicate) lines. |

---

## Quick Revision

- `-c` → Count duplicate lines.
- `-d` → Show only duplicate lines.
- `-u` → Show only unique (non-duplicate) lines.

> **Note:** `uniq` works only on **consecutive (adjacent)** duplicate lines. Use `sort` before `uniq` if duplicates are not adjacent.
